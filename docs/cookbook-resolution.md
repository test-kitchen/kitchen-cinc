# Cookbook Resolution

kitchen-cinc resolves cookbook dependencies before staging the sandbox.
Three modes are supported:

1. **Policyfile** — used automatically when a `Policyfile.rb` is
   present in `kitchen_root` (or at `policyfile_path`).
2. **Berkshelf** — used when no Policyfile is found and a `Berksfile`
   is present in `kitchen_root` (or at `berksfile_path`).
3. **None** — if neither file is present, kitchen-cinc copies
   cookbooks from standard layout directories without resolution.

Policyfiles are not supported by `cinc_solo`; it falls back to
Berkshelf or no resolution.

## Policyfile options

### `policyfile_path`

- **Type:** String
- **Default:** auto-detected
- Path to the `Policyfile.rb` to use. Relative paths are resolved from
  `kitchen_root`. If set but the file does not exist, kitchen raises a
  `UserError`.

### `policyfile` (legacy)

- **Type:** String
- **Default:** none
- Backward-compatible alias for `policyfile_path` (originally used by
  `policyfile_zero`). Prefer `policyfile_path`.

### `policy_group`

- **Type:** String
- **Default:** none
- Policy group passed to `chef export`. Required if your Policyfile
  defines multiple groups.

## Berkshelf options

### `berksfile_path`

- **Type:** String
- **Default:** auto-detected
- Path to the `Berksfile` to use. Relative paths are resolved from
  `kitchen_root`. If set but the file does not exist, kitchen raises a
  `UserError`.

### `berksfile`

- **Type:** `String`
- **Default:** `none`
- **Description:** Alternate spelling of `berksfile_path`, accepted for
  compatibility. `berksfile_path` takes precedence when both are set; if
  neither is set, `Berksfile` is used.

## Shared options

### `always_update_cookbooks`

- **Type:** Boolean
- **Default:** `true`
- When `true` (the Test Kitchen default for projects generated by
  `chef generate`), cookbook dependencies are re-resolved on every
  converge. Set to `false` to reuse a previously-resolved set.

### `cookbook_files_glob`

- **Type:** String (comma-separated globs)
- **Default:**

  ```text
  README.*,VERSION,metadata.{json,rb},attributes.rb,recipe.rb,
  attributes/**/*,definitions/**/*,files/**/*,libraries/**/*,
  providers/**/*,recipes/**/*,resources/**/*,templates/**/*,
  ohai/**/*,compliance/**/*
  ```

- File patterns staged into the sandbox when copying cookbooks. Files
  outside this glob are not transferred to the test instance.
